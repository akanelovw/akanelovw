## 🚀 Ключевой проект

### [TaskTracker](https://github.com/akanelovw/TaskTrackerClean)
Система управления проектами и задачами на чистой архитектуре, с desktop-клиентом.

`ASP.NET Core 10` · `EF Core` · `MS SQL Server` · `JWT + Identity` · `.NET MAUI` · `Docker` · `xUnit`

- Clean Architecture: Domain / Application / Infrastructure / WebApi
- Ролевая модель доступа (Admin / ChiefProjectManager / ProjectManager / Worker) — проверки и на клиенте, и на сервере
- Desktop-клиент на .NET MAUI с offline-конфигом и устойчивым к обрывам соединения HTTP-клиентом
- Docker Compose + Caddy: автоматический HTTPS через Let's Encrypt
- Unit- и интеграционные тесты, CI на GitHub Actions
